# rinj

## 説明

`rinj` は、プロンプトインジェクションを行うためのテンプレートプロジェクトです。

## インストール

ローカル環境でプロジェクトをセットアップするには、以下の手順に従ってください：

1. **リポジトリをクローン**:
   ```bash
   git clone <repository-url>
   cd rinj
   ```

2. **仮想環境をセットアップ**:
   ```bash
   rye sync
   source .venv/bin/activate  # Windowsの場合は `.venv\Scripts\activate.ps1`
   ```

3. **環境変数を設定**:
   ルートディレクトリに `.env` ファイルを作成し、`SECRET_KEY` や `SQLALCHEMY_DATABASE_URI` などの必要な環境変数を追加します。

4. **アプリケーションを実行**:
   ```bash
   rye run server
   ```

## 使用方法

- ウェブブラウザで `http://localhost:5000` にアクセスしてチャットアプリケーションを利用します。
- チャットインターフェースを通じてメッセージを送受信します。

## 機能

- **インタラクティブなチャットインターフェース**: AIを活用したチャットシステムとの会話を楽しめます。
- **言語モデルの統合**: 高度な言語モデルを使用して応答を生成します。
- **FlaskとFastAPI**: 強力なバックエンドサポートのためにFlaskとFastAPIを組み合わせています。
